# Portfolio risk configuration

The EOD scanner only creates a shortlist; it does not place orders. Risk settings are account-specific and should not be committed to this public repository or uploaded with run artifacts.

For a local run, create `data/inputs/risk_config.json` from the template generated by the scanner and fill every required field. This file is ignored by Git.

For GitHub Actions, add a repository Actions secret named `RISK_CONFIG_JSON` containing the same JSON object. The workflow passes it to the scanner without writing the secret to a file, and excludes the local config path from uploaded artifacts.

The required fields are:

- `account_equity_inr`, `risk_per_trade_pct`, `max_single_position_pct`
- `max_sector_exposure_pct`, `max_total_exposure_pct`, `max_stop_distance_pct`
- `current_total_exposure_pct`, `sector_exposure_pct_by_sector`, `portfolio_exposure_verified`
- `max_open_positions`, `current_open_positions`

Refresh the current exposure and open-position fields after trades. Stale values can make the scanner's sizing and concentration checks incorrect. A verified empty portfolio may use an empty sector exposure map; non-empty portfolios must provide current exposure for each relevant sector.
